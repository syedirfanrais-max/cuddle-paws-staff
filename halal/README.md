# The halal site

A free halal food website: weekly halal meal plans for home cooking, and a halal
restaurant finder for eating out and travel. Working name until Irfan chooses one.

This folder holds everything for the project. It sits inside the `cuddle-paws-staff`
repository for now and will move to its own repository later. It has nothing to do
with Cuddle Paws.

Start here:
1. `CLAUDE.md`: rules for every session.
2. `PRODUCT.md`: what the site is, what is decided, what is open.
3. `ops/team/TEAM.md`: how the bots work together.
4. `docs/research/phase1-competitor-study.md`: the competitor study.
5. `docs/handover/HANDOVER-NEW-SITE.md`: the method handed over from EveryNearby.
